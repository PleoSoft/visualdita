# Visual DITA

Write DITA like a document: topics and maps on a page, the way you write in Word, and the files stay valid DITA.

- **Visual DITA and how to install it:** <https://visualdita.com>
- **A problem or an idea:** open an issue here (Issues › New issue).

## Privacy

Visual DITA collects nothing and sends nothing anywhere. It reads and writes your files and its own settings on your
computer, and nothing leaves your machine.
